账号组由 Worker 解密后选择 DELETE_GROUP，不能通过密码 DELETE 先软删除再在 UI 隐藏。历史软删除组会明确报错并阻断同步，交由实施方核对，前端不会擅自恢复或清理它们。

恢复／永久删除不追加近期 Passkey。恢复直接提交；永久删除默认聚焦取消，取消／Escape 不发请求；两项操作在提交或结果未知期间同时禁用。未知结果先查询详情，再用完全相同正文及幂等键获取原回执，随后同步当前状态；详情 404 不被当成原操作成功证明。

## 当前真实联调依赖

只读调用当前环境的 CORS 预检返回 204，但 `Access-Control-Allow-Headers` 不含 `X-Vault-Lifecycle-Version`；已删除列表及详情的无会话访问返回 401。前端已经发送 v2 请求头，不能移除协商头绕过此问题。

需由后端运行环境实施方放行生命周期请求头，并确认部署了对应 R1/R2 代码和两个增量迁移、30 天清理策略及 SOURCE 支持；随后使用真实完整 MFA 会话执行上表待验收项。本轮没有真实完整 MFA 会话下的生命周期变更回执，没有修改 Java 仓库、环境配置或业务数据库。
